# mini-projeto-ml-financeiro
Pipeline de PLN para análise de sentimento no mercado financeiro. Inclui limpeza e EDA, amostragem balanceada por classe e vetorização com TF-IDF, Word2Vec customizado e GloVe pré-treinado. Usa Python, Pandas, NumPy, Scikit-Learn, NLTK, Gensim, Matplotlib e KaggleHub. Desenvolvido por Assis Vieira e Salomão.
